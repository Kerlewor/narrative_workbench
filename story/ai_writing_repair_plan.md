# AI 写作修复计划

## 常见问题

| 问题 | 症状 | 修复方式 |
| --- | --- | --- |
| 抽象心理 | “她感到很难过” | 改为动作、物件、呼吸、视线 |
| 主题总结 | “这就是她的成长” | 删除，用后续行动证明 |
| 段落过碎 | 连续短段没有节奏功能 | 合并或补足动作后果 |
| 对白串味 | 每个人说话都像同一个人 | 读取角色卡，按口癖和立场重写 |
| 信息越界 | 角色知道了未获知事实 | 改为猜测、误判或删除 |
| 配角降智 | 对手为推进剧情犯低级错 | 给对手合理目标和反制 |
| 伏笔漂移 | 规划钩子提前进状态文件 | 从状态文件移回 runtime |

## 修复顺序

1. 连续性和事实源。
2. 信息边界。
3. 人物动机。
4. 场景功能。
5. 文风和句子。
6. 格式。
