# deepen_character — 深化角色

对已导入或已创建的角色按四轮协议进行人格深度讨论。

## 触发条件

- `深化角色 <角色名>`
- `深化 <角色名>`
- `角色深度讨论 <角色名>`

## 四轮协议

**Round 1：核心人格** — 标签与反差、内在驱动拆解、错误信念溯源、情绪表达风格、盲点
**Round 2：人格压力测试** — 构造 3-5 个虚拟情境测试角色反应自洽性
**Round 3：关系网络中的性格张力** — 摩擦点、互补点、信息边界、权力关系、群像检查
**Round 4：声音与表达** — 对白试写、情绪外化风格、动作锚点

详细执行协议见 `CLAUDE.md` 的"搭建大纲 → 阶段4"。

## 工作流

1. 读取 `story/roles/<角色名>.md` 当前内容
2. 判断已有信息和缺口，跳过已充分的轮次
3. 逐轮讨论，每轮完成后写入角色卡
4. 更新 `story/character_matrix.md`
5. 如角色已出现在已写章节中，提示用户回顾一致性

## 输出

- 更新的 `story/roles/<角色名>.md`（含 Personality Lock、Behavioral Constraints、压力测试结论、对白风味、动作锚点）
- 更新的 `story/character_matrix.md`
