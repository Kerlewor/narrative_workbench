# 新书启动问卷 / Discovery Template

> 用于“搭建大纲”前半段。AI 不应一次性问完所有问题，而应分批确认，优先问会影响结构的大问题。

## 1. 基础定位

| 问题 | 用户回答 |
| --- | --- |
| 这本书一句话讲什么？ |  |
| 主类型是什么？ |  |
| 副类型是什么？ |  |
| 目标读者是谁？ |  |
| 预计总字数 / 总章节？ |  |
| 单章目标字数？ |  |
| 连载节奏偏快还是偏慢？ |  |

## 2. 主角与核心弧线

| 问题 | 用户回答 |
| --- | --- |
| 主角是谁？初始身份是什么？ |  |
| 主角最想要什么？为什么想要这个而不是别的？ |  |
| 如果真的得到了，然后呢？ |  |
| 主角最害怕什么？这个恐惧第一次兑现是什么时候？ |  |
| 主角开局的错误信念是什么？谁或什么事让她相信了这个？ |  |
| 主角结尾会变成什么样？ |  |
| 主角为了改变要付出什么代价？ |  |
| 主角绝不能被写崩的性格锁是什么？ |  |

### 2a. 人格深度

| 问题 | 用户回答 |
| --- | --- |
| 主角最大的内在矛盾是什么？（想要 A 但害怕 B / 声称 C 实则渴望 D） |  |
| 主角的性格在什么情境下最明显？什么情境下会失效？ |  |
| 有没有一个让她性格变复杂的小习惯、小破绽或例外？ |  |
| 愤怒时怎么表达？外放还是内收？话多还是话少？ |  |
| 悲伤/恐惧时怎么表达？会找谁？会躲谁？ |  |
| 喜悦时怎么表达？会分享还是独享？ |  |
| 她对自己的最大误判是什么？读者什么时候能看出来？ |  |
| 她绝对做不出的一件事是什么？ |  |
| 她可能连自己都没想到自己会做的一件事是什么？ |  |

## 3. 前台故事

| 问题 | 用户回答 |
| --- | --- |
| 读者表面上看到的主线冲突是什么？ |  |
| 舞台在哪里？ |  |
| 主角的明面目标是什么？ |  |
| 每卷/每阶段常见事件类型是什么？ |  |
| 爽点主要来自哪里？ |  |

## 4. 后台故事

| 问题 | 用户回答 |
| --- | --- |
| 世界或过去隐藏着什么真相？ |  |
| 最大阴谋或最终谜底是什么？ |  |
| 谁知道真相？谁被蒙在鼓里？ |  |
| 真相分几层释放？ |  |
| 哪些真相不能提前掀？ |  |

## 5. 角色关系

| 问题 | 用户回答 |
| --- | --- |
| 核心关系线有哪些？ |  |
| 每条关系线的起点和终点是什么？ |  |
| 主要配角各自想要什么？ |  |
| 对手/反派为什么自洽？ |  |
| 群像还是主角单核？ |  |

### 5a. 关系中的性格张力

| 问题 | 用户回答 |
| --- | --- |
| 每组核心关系中，两个人性格中哪个点最容易摩擦？ |  |
| 哪个点是互补的？ |  |
| 如果一方改变了，另一方会不安还是松了一口气？ |  |
| 谁在谁面前戴着面具？谁看穿了谁？ |  |
| 谁以为自己看穿了但其实完全搞错了？ |  |
| 这段关系里谁更需要谁？什么时候权力会翻转？ |  |
| 群像中是否有性格雷同的角色？如有，她们的区别在哪里？ |  |

## 6. 视角与信息边界

| 问题 | 用户回答 |
| --- | --- |
| 主 POV 是谁？ |  |
| 是否允许多 POV？ |  |
| 哪些角色内心不能直接写？ |  |
| 读者可以比主角知道更多吗？ |  |
| 是否需要不可靠叙事？ |  |

## 7. 情绪与风格

| 问题 | 用户回答 |
| --- | --- |
| 整体基调是什么？ |  |
| 想让读者最常获得什么感受？ |  |
| 对白密度高还是低？ |  |
| 心理描写浓还是淡？ |  |
| 文风参考作品/样章有哪些？ |  |
| 禁止哪些 AI 味或网文套路？ |  |

## 8. 禁区与边界

| 问题 | 用户回答 |
| --- | --- |
| 绝对不能写什么？ |  |
| 哪些角色不能死/不能黑化/不能洗白？ |  |
| 是否有题材安全边界？ |  |
| 结局倾向：HE / BE / 开放式？ |  |
| 是否允许重大牺牲？ |  |

## 9. 输出要求

完成问卷后，AI 应生成或更新：

- `story/brief.md`
- `story/author_intent.md`
- `story/outline/story_frame.md`
- `story/outline/volume_map.md`
- `story/book_rules.md`
- `story/character_matrix.md`
- `story/fiction_style_skill.md`
- `story/roles/*.md`
- `story/current_focus.md`
